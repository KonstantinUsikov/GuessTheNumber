# Клиент-серверная игра "Угадай число" с использованием собственного протокола

Сервер загадывает случайное число в заданном диапазоне, а клиент пытается его угадать. После каждой попытки сервер сообщает, больше или меньше загаданное число. Клиент и сервер общаются по TCP с помощью собственного бинарного протокола, пакеты которого можно шифровать алгоритмом AES.

## Структура решения

| Проект | Описание |
|---|---|
| `ClassLibraryMyProtocol` | Библиотека протокола: пакеты, сериализатор, шифрование, классы `Client`, `Server` и `ConnectedClient` |
| `WpfAppServer` | Сервер с графическим интерфейсом. Берёт IP и порт из JSON-файла и выводит лог игры |
| `WpfAppClient` | Клиент с графическим интерфейсом: подключение к серверу, выбор диапазона и угадывание числа |
| `WpfLibrary` | `WpfUiDispatcher`, реализация `IUiDispatcher` для обращения к элементам формы из других потоков |
| `ConsoleServer` | Консольный сервер на `127.0.0.1:8080` |
| `ConsoleClient` | Консольный клиент, который выполняет зашифрованное рукопожатие с сервером |
| `ConsoleTest` | Ручная проверка сериализации и шифрования пакетов |

## Требования

- .NET 7 SDK
- Windows для WPF-проектов (`net7.0-windows`)

## Запуск

Сборка решения:

```sh
dotnet build GuessTheNumber.sln
```

### Сервер

```sh
dotnet run --project WpfAppServer
```

При запуске сервер откроет окно выбора файла настроек. Нужен JSON-файл такого вида:

```json
{ "Ip": "127.0.0.1", "Port": 8080 }
```

### Клиент

```sh
dotnet run --project WpfAppClient
```

1. Введите адрес сервера в формате `IP:port`, например `127.0.0.1:8080`, и нажмите «Подключиться».
2. Укажите минимум и максимум диапазона и нажмите «Начать».
3. Вводите числа и нажимайте «Отправить». Ваши попытки появятся в списках «Больше чем» и «Меньше чем», пока число не будет угадано.

### Консольные приложения

`ConsoleServer` запускает сервер на `127.0.0.1:8080`, а `ConsoleClient` подключается к нему и выполняет рукопожатие:

```sh
dotnet run --project ConsoleServer
dotnet run --project ConsoleClient
```

## Протокол

### Формат пакета

| Часть | Размер | Значение |
|---|---|---|
| Заголовок | 3 байта | `AF AA AF` для обычного пакета, `95 AA FF` для зашифрованного |
| Тип | 1 байт | Тип пакета |
| Подтип | 1 байт | Подтип пакета |
| Поля | переменный | Последовательность `[id][size][data]` |
| Окончание | 2 байта | `FF 00` |

Длина пакета не превышает 256 байт, а размер одного поля не превышает 255 байт.

### Типы пакетов

| `MyPacketType` | Тип | Подтип |
|---|---|---|
| `Handshake` | 1 | 0 |
| `GuessTheNumber` | 2 | 0 |

### Сериализация

`MyPacketSerializer` превращает объект в пакет и обратно. В пакет попадают поля класса, помеченные атрибутом `[MyField(id)]`:

```csharp
public class GuessTheNumberPacket
{
	[MyField(1)] public int Min;
	[MyField(2)] public int Max;
	[MyField(3)] public int Guess;
	[MyField(4)] public int LessOrMore;
	[MyField(5)] public int NewGame;
}
```

### Шифрование

Используется AES. Ключ получается как SHA-256 от кодового слова, а случайный вектор инициализации (IV) записывается перед зашифрованными данными. При шифровании исходный пакет целиком помещается в поле с `id = 0` нового пакета с заголовком `95 AA FF`. При разборе такой пакет расшифровывается автоматически.

## Ход игры

1. **Рукопожатие.** Клиент отправляет `MagicHandshakeNumber = 12`, сервер отвечает `13`.
2. **Новая игра.** Клиент отправляет `GuessTheNumber` с `NewGame = 1`, `Min` и `Max`. Сервер загадывает случайное число из диапазона `[Min, Max]` и отвечает пакетом с `NewGame = 1`.
3. **Попытка.** Клиент отправляет `Guess`. Сервер отвечает тем же `Guess` и значением `LessOrMore`:
   - `-1`: названное число меньше загаданного;
   - `1`: названное число больше загаданного;
   - `0`: число угадано.
